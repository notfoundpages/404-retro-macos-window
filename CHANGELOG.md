# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.1.0] - 2026-08-07

### Added

- Added GitHub issue forms for bug reports, feature requests, and new 404 page submissions
- Added a simplified pull request template for clearer contribution workflows
- Added support for submitting new 404 page designs to the Not Found Pages ecosystem

### Changed

- Redesigned the README with a cleaner showcase-focused layout
- Improved project introduction, preview section, and setup instructions
- Added inline version documentation for single-file usage
- Simplified contribution guidelines to make contributing easier
- Updated JSON-LD metadata structure for better website compatibility
- Replaced the color controls video preview with a GIF for better README compatibility

### Removed

- Removed outdated issue templates and replaced them with GitHub issue forms
- Removed unused GitHub funding configuration
- Removed unnecessary preview assets
- Removed outdated and overly detailed contribution documentation

### Maintenance

- Improved repository organization and contributor experience
- Updated project documentation to better match the Not Found Pages ecosystem

## [1.0.0] - 2026-03-19

### Added

- Retro macOS-inspired 404 page with authentic desktop-style layout
- Interactive title bar control buttons styled after macOS window controls
- Dynamic background color switching triggered by title bar controls
- CSS grid background pattern with parallax-style visual depth
- Responsive layout for mobile, tablet, and desktop screens
- Multiple preview assets for desktop, mobile, and social sharing
- Multiple color variants including blue, red, yellow, and green
- Semantic HTML structure for improved accessibility
- Keyboard-accessible interactive controls
- Project documentation including README, contribution guide, and code of conduct
- MIT license
